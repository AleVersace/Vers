# README artwork

`vers-cover.webp` is a decorative illustration for the English and Italian
README files. It is not an application screenshot or a bundled playable map.

The image was generated for Vers with OpenAI's built-in image generation tool.
Its palette and diamond/V motif were described from the project's existing
styles and icon. No reference images, player uploads, campaign records, personal
information or installation addresses were supplied.

The generated image was encoded as WebP for a smaller download, with no EXIF,
XMP or color-profile metadata retained. The application icon is unchanged.
See the [project license](../../LICENSE).
